Click the picture, then type. Keys sit where they are on a C64 (like VICE's positional keymap): Esc = RUN/STOP, Page Up = RESTORE, Tab = CTRL, Left Ctrl = C=, Home = CLR/HOME, Backspace = DEL, Insert = INST, - = +, = = −, [ = @, ] = *, ; = :, ' = ;, \ = £, ` = ←, Delete = ↑, End = =, F2/F4/F6/F8 = Shift + F1/F3/F5/F7. Shifted symbols are typed as on a C64 (Shift+2 = ").
